# 相簿与轮播

照片保存在共用服务器，ESP 只保存轮播配置、请求二进制图片，不占用设备 Flash 存照片。先按 [额外服务部署](services.md) 启动或更新服务器，在设备设置中保存一次服务地址。

## 保存照片

1. 打开「拍立得」，选择照片并调整裁剪、四色风格、留白和文字。
2. 点击「保存当前画面到相簿」。保存的是处理后的完整展示画面，预览与设备下载的图片像素一致，原始照片不上传。
3. 进入「相簿」，点击缩略图预览。便签画面也可以保存。

服务器自动按 `20261013-143532-a1b2c3d4` 格式命名：保存时间与图片帧 SHA-256 的前 8 位。相簿卡片只显示简短时间和哈希，不展示原始文件名。

保存到相簿不会刷新设备，也不会停止正在运行的自动卡片。「上传并刷新屏幕」才会切换设备到手动画面，并关闭天气、音乐和相簿轮播。

## 开始轮播

1. 在「相簿」勾选需要播放的照片，或点击「全选照片」。最多选择 256 张。
2. 选择「顺序循环」或「随机播放」。顺序按保存时间排列；随机模式在有多张照片时不连续重复同一张。
3. 设置切换间隔，默认 30 分钟，可设为 1–1440 分钟。
4. 启用轮播并点击「保存轮播设置」。设备会请求第一张照片，然后按间隔切换；「下一张」可以立即请求切换。

相簿、天气和音乐互斥，启用并保存其中一项会关闭另外两项，前端开关同步。关闭后保留当前画面与配置，重启后不会自动恢复被关闭的模式。设备断网或请求失败时保留画面，约 30 秒后重试；只有一张照片时保留该画面，不反复刷新。

照片保留保存时的屏幕尺寸（768×552 或 A1 原生 800×600）。轮播自动跳过与当前设备尺寸不匹配的照片；切换屏幕配置后，请重新保存匹配尺寸的照片。

## 存储与多台设备

服务器默认保存到工作目录的 `data/album.sqlite3`，可用 `--data-dir /持久存储目录` 指定路径。照片、预览和轮播列表均持久保存，更新服务时保留该目录；服务停止后可复制数据库备份。

多台设备共用一个照片库，但各自保存轮播选择、模式和间隔，各自推进播放位置，设备重启后从列表重新开始。删除照片会影响所有使用该照片的设备；设备会跳过已删除照片。如果轮播列表已无可用照片，屏幕保留原画面，网页显示更新失败。

## HTTP 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/v1/album/photos` | 照片列表（ID、名称、保存时间、尺寸） |
| POST | `/v1/album/photos?name=照片名称` | 保存处理后的帧，正文为 `application/octet-stream` |
| GET | `/v1/album/photos/{id}.png` / `.bin` | PNG 预览 / 原始二进制帧 |
| DELETE | `/v1/album/photos/{id}` | 删除照片 |
| POST | `/v1/album/playlists` | 保存选择，JSON 正文为 `{"photos":["照片ID"]}`，返回列表 ID |
| GET | `/v1/album/playlists/{id}` | 读取照片选择 |
| GET | `/v1/album/next.json?playlist=列表ID&current=当前照片ID&mode=sequence&width=768&height=552` | 获取下一张照片，`mode` 也可为 `random` |

设备配置接口见 [HTTP API](API.md)。
