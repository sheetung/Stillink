# 待办

更新并启动[额外服务](services.md)，在设备设置中保存服务地址和服务密钥。检测到待办服务可用后，网页显示「待办」入口。旧版服务需要更新后才能使用。

卡片包含日期、星期和完成进度；天气沿用设备天气页已保存的位置，未配置时只显示日期，天气请求失败不影响待办展示。仍需手动上传更新屏幕。

## 使用

1. 输入事项并添加，点击复选框标记完成，也可删除事项。
2. 查看左侧预览；超过 8 项时，使用上一页、下一页选择要显示的页面。
3. 点击「上传并刷新屏幕」，将当前预览发送到墨水屏。

清单最多 100 项，每项最多 120 字。未完成事项优先显示，已完成事项带勾和删除线。修改立即保存到服务，多台手机或电脑共用；打开待办页时每 15 秒同步一次，也可手动重新加载。

修改清单不会自动刷新墨水屏。手动上传成功后停止天气、音乐和相簿轮播，保留它们的配置；上传失败不会关闭自动更新。

## 数据与备份

清单保存在服务的 `data/todo.sqlite3`，不占用 ESP 的持久存储。升级服务或替换 Windows EXE 时保留 `data` 文件夹。备份前先停止服务，再复制整个 `data`。

## HTTP 接口

以下接口均需要服务密钥：`Authorization: Bearer <service_key>`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/v1/todo/items` | 获取共享清单 |
| POST | `/v1/todo/items` | 添加，JSON `{"text":"给绿植浇水"}` |
| POST | `/v1/todo/items/{id}` | 更新完成状态，JSON `{"done":true}` |
| DELETE | `/v1/todo/items/{id}` | 删除事项 |
| GET | `/v1/todo/card.png` | 当前清单的预览 |
| GET | `/v1/todo/card.bin` | 可上传到设备的二进制图片 |

列表响应为 `{"items":[{"id":"…","text":"…","done":false,"created":0}],"page_size":8}`；增删改返回最新完整列表。图片可附带 `date`（YYYY-MM-DD），以及 `latitude`、`longitude`、`name` 天气位置参数。图片支持 `page`（从 0 开始）、`width`、`height`、`panel` 参数；尺寸支持 `768×552`、`800×600`，面板为 `0` / `1`。页码超出范围返回 400。

取得二进制后，使用**设备登录令牌**提交到 `POST /api/frame`，并设置 `Content-Type: application/octet-stream`。服务密钥与设备令牌不可混用，详见 [HTTP API](API.md)。
