# Windows 免安装额外服务

1. 将 `StillinkServices-win.zip` 完整解压到可写目录，不要直接在压缩包中运行。
2. 双击 `StillinkServices.exe`，无需安装 Python、uv 或中文字库，依赖已包含在单个 EXE 中。
3. 启动窗口会列出本机局域网地址，分别复制地址和服务密钥，填入 ESP 的「设备设置 → 额外服务支持」并保存。多网卡时选择与 ESP 同一网络的地址。
4. Windows 防火墙首次提示时允许专用网络访问。HTTP 使用 TCP 8787，音乐接收使用 UDP 8790。

关闭窗口后服务继续在任务栏通知区域运行。右键托盘图标可显示服务地址或退出。

## 升级

先从托盘退出服务，将新版 `StillinkServices.exe` 替换到原目录，再双击启动即可。不要删除、移动或覆盖旁边的 `data` 文件夹，照片、轮播列表、待办和 `service.key` 服务密钥都保存在其中。升级包只包含 EXE 和使用说明，不包含数据目录，程序启动和升级不会清空已有数据库。

天气、相簿、待办可直接使用。音乐仍需另行运行 `StillinkMusic.exe` 广播当前歌曲，Windows 音乐工具可以与本服务在同一台电脑运行；两者无需填写彼此地址。

照片保存在 `data/album.sqlite3`，待办保存在 `data/todo.sqlite3`。备份时先退出服务，再复制 `data`。启动异常可查看 `services.log`；重复启动或端口被占用时会显示错误提示。

服务需保持运行。本程序仅供局域网使用，不要将端口映射到公网。电脑关机或休眠后自动更新暂停，ESP 保留当前画面。

窗口中可更换服务密钥，修改后设备需重新填写，原照片不删除。设备登录密钥与服务密钥互不影响。
