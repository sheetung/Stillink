Stillink V1.0.0 — ESP32-S3 刷机包
发布日期：2026-10-12；HTTP API / 帧契约版本：2。

文件说明
- Stillink一键刷机.bat：Windows 一键刷机入口。
- flash_on_pc.py：只支持 ESP32-S3 的刷机脚本。
- stillink_V1.0.0_merged.bin：整包固件，写入地址 0x0。
- stillink_V1.0.0_app.bin：应用固件，供现有同分区表 S3 设备网页 OTA。
- page-V1.0.0.html：控制页，可在网页升级入口单独更新。
- test_frame_post.py：通过 HTTP 上传四色测试帧。
- esp32s3/：相同固件的带芯片名称文件，接线见该目录说明。

首次烧录
1. 用数据线连接 ESP32-S3，双击 Stillink一键刷机.bat。
2. 如需指定端口：python flash_on_pc.py --port COM13
3. 失败时拔插 USB；若卡在 Stub running，可尝试 --no-stub。
4. 连接 Stillink-XXXX 热点，访问 http://192.168.4.1。
整包刷写会覆盖现有固件与分区初始数据，建议事先记录设备设置。

网页升级
在设备设置的升级入口上传 stillink_V1.0.0_app.bin，等待重启。
现有固件必须为 ESP32-S3 且使用相同分区表，其他芯片不能使用此固件。
上传 page-V1.0.0.html 仅更新控制页，刷新浏览器生效。

使用与休眠
- Wi-Fi 名称点击后自动扫描，连接并保存 2.4 GHz 路由器网络。
- 获得局域网 IP 后约 10 秒关闭热点，通过该 IP 操作；断网后恢复热点。
- 联网空闲时自动轻睡，保持连接并恢复处理 HTTP 请求；刷新屏幕期间保持运行。
- 未联网时默认空闲 3 分钟进入深睡，GPIO5 接地按键或定时器唤醒。
- HTTP 接口及二进制帧格式见仓库 docs/API.md。
- USB 调试连接可能阻止实际轻睡，功耗需测量。
